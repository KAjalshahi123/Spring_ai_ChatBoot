# 🤖 Spring AI Chatbot (Spring Boot + OpenAI)

## 📌 Project Overview
This project is an AI-powered chatbot application built using **Spring Boot** and **Spring AI**. It integrates with OpenAI APIs to generate intelligent and real-time responses based on user input.

---

## 🚀 Features
- AI-powered chatbot using OpenAI
- REST API-based backend
- Real-time response generation
- Simple and scalable architecture
- Easy integration with frontend (optional)

---

## 🛠️ Tech Stack
- Java
- Spring Boot
- Spring AI
- OpenAI API
- Maven

---

## ⚙️ How It Works
1. User sends a message (input prompt)
2. Backend (Spring Boot) receives the request
3. Spring AI sends the request to OpenAI API
4. AI generates a response
5. Response is returned to the user
